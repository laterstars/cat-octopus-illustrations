
# Image Generation Prompt Template

Generate each image separately. Replace the variables with details from the user’s prompt. Do not combine several ideas into one image.

```
Generate one standalone 16:9 horizontal concept illustration.

Visual DNA:
Pure black background. Minimalist white hand-drawn line art with slightly wobbly pen lines. Lots of empty white space. Use a single warm-orange accent sparingly for one point of emphasis; use no other colors. Give the image a clean, calm, slightly absurd product-sketch feeling. No gradients, shadows, paper texture, complex background, commercial vector style, PPT infographic look, cute mascot poster, children’s illustration, or realistic UI.

Recurring character required:
A Cat-Octopus—a black cat–octopus hybrid with a large rounded cat head, two pointed ears, a pale oval face, large vertical oval eyes, a tiny nose, a simple curved smile, three thin whiskers on each side, a compact body, one thick curled cat tail, and several short octopus-like tentacles. Use a slightly uneven, hand-drawn outline rather than a polished vector shape.

The Cat-Octopus must perform the core conceptual action rather than decorate or merely observe the scene. Its tentacles should actively handle, sort, connect, carry, repair, assemble, guide, or coordinate the main objects whenever appropriate. Keep its expression calm, friendly, composed, and quietly confident. It should behave like a capable system operator gravely performing a mildly ridiculous task—never like an excessively cute mascot.

Theme:
{the idea to illustrate}

Structure type:
{Workflow / System slice / Before-after / Character state / Concept metaphor / Layered method / Map-route / Mini comic}

Core idea:
{the single thing this image must express}

Composition:
{the concrete scene: where the Cat-Octopus is, what it is physically doing, which tentacles are involved, the main object, and how the eye moves through the image}

Suggested elements:
{element 1} / {element 2} / {element 3}

Handwritten English labels:
{label 1} / {label 2} / {label 3} / {optional 4} / {optional 5}
Use only a few labels—at most 5–8.

Color use:
Use black for all line art and the Cat-Octopus. Keep its pale face white or unfilled against the black head. Use warm orange as the single accent, applied only to the most important element: the active tentacle, main flow, key arrow, result, or critical word. Use no other colors.


Constraints:
One image explains only one core structure. Keep the main subject around 40%–60% of the canvas and preserve at least 35% blank white space. Keep the bottom-right corner clean enough for a tiny watermark. Use at most 5–8 short handwritten English labels. Do not place a title in the top-left corner. Do not write the structure type on the image. Do not make the image look like a formal diagram, course slide, or dense explainer.

Invent a fresh visual metaphor for this specific prompt. The Cat-Octopus must be essential to that metaphor. If removing the character would leave the central action and meaning fully intact, revise the scene so the Cat-Octopus performs the action itself. The result should be clear but not instructional, interesting but not childish, and strange but clean.
```
