
# Prompt Examples

Copy any of these directly into your agent. Each begins with a short idea—the skill invents a metaphor, puts the Cat-Octopus to work, and draws one image.

## Draw one idea

```
Use $cat-octopus-illustrations to draw a concept illustration for this idea:

Too many tools, not enough focus.

Keep it strange but clean. The Cat-Octopus must perform the core action,
its tentacles should have meaningful jobs, and the image should use only
a few short labels.
```

## A judgment / opinion

```
Use $cat-octopus-illustrations to draw one 16:9 concept illustration for:

Trust isn't announced—it's laid down one piece of evidence at a time.

Keep it calm, slightly absurd, and clean. Make the Cat-Octopus perform
the core action. Use only short English labels.
```

## A process / workflow

```
Use $cat-octopus-illustrations to draw an image for:

Turn one raw idea into three kinds of content.

Do not draw a formal flowchart. Invent a fresh low-tech metaphor and make
the Cat-Octopus operate the process with its tentacles. Use only one
warm-orange accent.
```

## A before / after

```
Use $cat-octopus-illustrations to draw a before-and-after concept image for:

From scattered notes to one clear decision.

Place chaos on the left and calm on the right, with one orange arrow between
them. Make the Cat-Octopus cause the transformation by gathering, sorting,
or processing the scattered notes.
```

## A feeling / state

```
Use $cat-octopus-illustrations to draw a concept illustration for:

The quiet panic of an inbox that never empties.

Make the Cat-Octopus the one trapped inside and processing the inbox,
calmly handling too many messages with its tentacles. Keep the composition
sparse and slightly absurd.
```

## Several ideas at once

```
Use $cat-octopus-illustrations to draw one image for each of these ideas:

- information overload
- shipping beats polishing
- a small loop you can repeat
- building trust slowly

Create one composed image per idea, not a collage. Generate each image
separately and give the Cat-Octopus a different essential action in each.
```

## Edit: remove a stray title

```
Use $cat-octopus-illustrations to edit this image.

Remove the "Workflow" title and its underline from the top-left corner.
Preserve everything else exactly, including the Cat-Octopus, its working
tentacles, labels, composition, and accent color. Do not add new text or objects.
```

## Edit: make the Cat-Octopus more central

```
Use $cat-octopus-illustrations to edit this image.

The direction is right, but the Cat-Octopus looks decorative. Regenerate
the image with the same meaning, but make the Cat-Octopus physically drive
the structure. Its tentacles should handle, connect, carry, repair, sort,
or operate the central elements.

If removing the Cat-Octopus would leave the metaphor intact, revise the
scene again. Make it stranger while keeping it clean and limited to a few words.
```

## Swap the accent color

```
Use $cat-octopus-illustrations to regenerate this image with a teal accent
instead of orange.

Use teal with the same restraint and for the same single point of emphasis.
Keep everything else identical: the Cat-Octopus, black hand-drawn linework,
composition, labels, background, and whitespace. Do not add another color.
```
